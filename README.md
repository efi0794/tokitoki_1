# SECURITY DESKTOP — ハタンボ

情報セキュリティ研修向けの1ページ完結型謎解きゲームです。架空の研修メールから始まり、ウイルス感染演出、AIアシスタント「ハタンボ」と6つの謎、復旧までを体験できます。

## 使用技術

- HTML（`index.php` 内）
- CSS
- JavaScript
- PHP（セッション開始のみ。ゲーム進行はブラウザ内で完結）

## 起動方法

PHPが入っている環境で次を実行し、`http://localhost:8000` を開きます。

```bash
php -S localhost:8000
```

## 学習テーマ

1. フィッシングメール
2. パスワードの使い回し
3. 外部ネットワーク
4. 離席時の情報管理
5. 認証情報の共有
6. インシデント記録の確認

実在のパスワードや個人情報は入力させず、画面内の情報だけで解ける設計です。
